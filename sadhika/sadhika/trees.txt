Trees in DSA: Theoretical Overview

A tree is a non-linear, hierarchical data structure consisting of nodes connected by edges.
 Unlike arrays, linked lists, stacks, or queues (which are linear), trees represent relationships 
 such as parent-child, ancestor-descendant, or nested groupings.

1. Basic Terminology

· Node – Fundamental unit containing data and links to child nodes.
· Root – The topmost node; no parent. A tree has exactly one root.
· Edge – Connection between two nodes.
· Parent – A node that has one or more children.
· Child – A node directly reachable from its parent.
· Sibling – Nodes sharing the same parent.
· Leaf (External Node) – Node with no children.
· Internal Node – Node with at least one child.
· Subtree – Any node together with its descendants.
· Depth of a node – Number of edges from root to that node. Root depth = 0.
· Height of a node – Number of edges on the longest downward path from that node to a leaf. Leaf height = 0.
· Height of tree – Height of the root node.
· Level – Set of nodes at the same depth. Root at level 0.

2. Properties of a Tree (General Definition)

· Connected – There is a path between any two nodes.
· Acyclic – No cycles.
· For n nodes, there are exactly n−1 edges.
· Any two nodes are connected by exactly one unique path.

3. Types of Trees

3.1 Binary Tree

Each node has at most 2 children (left and right).
Strict/Proper binary tree – Every node has 0 or 2 children.
Complete binary tree – All levels filled except possibly last, which is filled left to right.
Full binary tree – Every node has 0 or 2 children (synonym of proper).
Perfect binary tree – All internal nodes have 2 children and all leaves at same level.

Properties (perfect binary tree of height h):

· Nodes = 2^{h+1} - 1
· Leaves = 2^h
· Height = \log_2(n+1) - 1

3.2 Binary Search Tree (BST)

Binary tree with ordering property:
Left subtree contains only nodes with keys less than node’s key; right subtree contains only keys greater (or greater/equal depending on definition).
Supports efficient search, insertion, deletion: O(h) time, where h is height. Worst-case h = O(n) if degenerate (like a linked list).

3.3 Self-Balancing BSTs

Maintain height O(log n) to guarantee operations in O(log n).
Examples:

· AVL Tree – Height difference (balance factor) between left and right subtrees ≤ 1. Rotations restore balance after insert/delete.
· Red-Black Tree – Nodes colored red/black with constraints (e.g., no two reds adjacent, same black depth to leaves). More relaxed than AVL, fewer rotations. Used in C++ std::map, Java TreeMap.
· Splay Tree – Recently accessed node moved to root via splay operations; amortized O(log n).
· B-Tree – Generalization with multiple keys per node (e.g., 2-3 tree, B+ tree). Used in databases and file systems (disk-based indexing) because they minimize disk I/O.

3.4 Heap

A complete binary tree satisfying heap property:

· Max-heap – Parent ≥ children (largest at root).
· Min-heap – Parent ≤ children (smallest at root).
  Used for priority queues, heap sort. Insert/delete in O(log n).

3.5 Trie (Prefix Tree)

A tree where edges represent characters (or bits) of a key. Nodes store whether a word ends there. Used in dictionary search, autocomplete, IP routing (radix tree). Space-efficient when many keys share prefixes.

3.6 Segment Tree

Binary tree used to store intervals or segments. Each node represents a range [L,R]; leaf nodes are single elements. Supports range queries (sum, min, max) and point updates in O(log n). Used in computational geometry and query problems.

3.7 Fenwick Tree (Binary Indexed Tree)

Array-based tree for prefix sum queries and point updates in O(log n). Simpler and less memory than segment tree, but less general (range updates require tricks).

3.8 Suffix Tree

Compressed trie of all suffixes of a string. Enables fast substring search (O(m) after O(n) construction). Used in bioinformatics and text processing.

3.9 Binary Space Partition (BSP) Tree

Splits space into convex subspaces by hyperplanes. Used in computer graphics (painter’s algorithm), collision detection.

4. Tree Traversals (Systematic visiting of nodes)

Depth-First Traversals (DFS)

· Preorder (Root → Left → Right): Used to copy a tree, generate prefix expression (polish notation).
· Inorder (Left → Root → Right): In BST, gives sorted order.
· Postorder (Left → Right → Root): Used to delete tree (delete children before parent), generate postfix expression.

Breadth-First (Level Order)

Level by level, left to right. Implemented with a queue. Used for shortest path in unweighted graphs,
 testing if tree is complete/perfect.

5. Applications of Trees

· File systems – Hierarchical directories are trees.
· HTML/XML DOM – Document Object Model is a tree.
· Compiler design – Abstract Syntax Tree (AST) represents program structure.
· Database indexing – B-trees and B+ trees enable fast search on disk.
· Network routing – Spanning trees (e.g., STP in Ethernet), tries for IP lookup.
· Artificial intelligence – Decision trees, game trees (minimax).
· Data compression – Huffman coding tree (optimal prefix code).
· Priority queues – Heaps.
· String matching – Trie, suffix tree.
· Cryptography – Merkle tree (blockchain).
· Range queries – Segment tree, Fenwick tree.

6. Advanced Theoretical Concepts

· Tree isomorphism – Determining if two trees have identical structure (ignoring data).
· Spanning tree – Subgraph of a graph that is a tree covering all vertices (used in MST: Kruskal, Prim).
· Binary tree representation – Using arrays (for complete/perfect trees) or linked nodes.
· Threaded binary tree – Adds pointers to inorder predecessor/successor for easier traversal without stack/recursion.
· Cartesian tree – Tree built from sequence where root is minimum/maximum; used in range minimum queries.
· Tree rotations – Local operation to change structure without breaking BST property (used in AVL, Red-Black).
· Amortized analysis – Applied to splay trees and some self-balancing structures.

7. Key Theorems & Relations

· In a binary tree, number of leaves = number of internal nodes + 1 (for proper binary trees).
· Minimum height of binary tree with n nodes: ⌈log₂(n+1)⌉ – 1.
· Maximum height (degenerate): n − 1.
· Number of different binary trees with n nodes (Catalan number): C_n = \frac{1}{n+1}\binom{2n}{n}.
· Height of AVL tree with n nodes ≤ 1.44 log₂(n+2) − 1.328.

8. Memory Representation

· Sequential (array) – For complete binary trees: for node at index i, left child = 2i+1, right = 2i+2, parent = floor((i−1)/2). Wastes space for non-complete trees.
· Linked representation – Each node has pointers to children (and optionally parent). Dynamic, no wasted space.

9. Complexity Summary (Balanced BST)

· Search: O(log n)
· Insertion: O(log n)
· Deletion: O(log n)
· Traversal: O(n)
· Space: O(n)
